<h2 id="redaction-retention">მტკიცებულებისა და პირადი მონაცემის ბალანსი</h2>
<p>Audit log-ს ორი ურთიერთდაკავშირებული რისკი აქვს. თუ ძალიან ცოტას ინახავთ, გამოძიება ვერ აღდგება. თუ ყველაფერს ინახავთ, თვითონ log შეიძლება გახდეს sensitive data ახალი საცავი. განსაზღვრეთ რომელი ველია აუცილებელი, რომელი უნდა დაიჰეშოს ან დაიმალოს და რომელ მომხმარებელს აქვს წვდომა.</p>
<p><a href="https://csrc.nist.gov/pubs/sp/800/92/final">NIST SP 800-92</a> computer security log management-ს ორგანიზებულ პროცესად განიხილავს. პრაქტიკულად ეს ნიშნავს, რომ retention მხოლოდ ტექნიკური პარამეტრი არ არის. უნდა არსებობდეს მოვლენის პასუხისმგებელი, დროის წყარო, წვდომის წესი, ექსპორტის გზა და წაშლის ან არქივის მოლოდინი. კანონიერი retention მოთხოვნები კონკრეტულ ორგანიზაციასა და იურისდიქციაზეა დამოკიდებული; ეს სტატია იურიდიულ რჩევას არ წარმოადგენს.</p>
<p>Correlation ID არსებობა სასარგებლოა მაშინ, როცა მისი გამოყენება request, worker და audit event-ს შორის თანმიმდევრულად ხდება. შემთხვევითი ID ჩაწერა ბიზნეს-მოქმედების, actor-ისა და target გარეშე გამოძიებას ვერ ცვლის.</p>

<h3 id="tamper-access">რას უნდა მიაქციოთ ყურადღება log მფლობელობაში?</h3>
<p>Audit evidence სანდოობა მხოლოდ ველების რაოდენობაზე არ არის დამოკიდებული. შეამოწმეთ, შეუძლია თუ არა იგივე აპის ადმინისტრატორს ჩანაწერის ჩუმად წაშლა, იცვლება თუ არა timestamp, აქვს თუ არა log store-ს ცალკე წვდომა და როგორ ფიქსირდება export. თუ ეს კონტროლები არ ჩანს, დასკვნა უნდა იყოს „არ არის დადასტურებული“ და არა „immutable“.</p>
<p>ბიზნეს-მფლობელს მიეცით პრაქტიკული გადაწყვეტილება: რომელი event-ები უნდა იყოს release წინ სავალდებულო, რომელი ველები ითვლება მგრძნობიარედ, ვინ ამოწმებს alert-ს და რომელი გარემო არ შედის scope-ში. Monitoring არსებობა audit trail integrity-ს ავტომატურად არ ამტკიცებს.</p>

<p>არა. error monitoring ტექნიკურ ჩავარდნებსა და ჯანმრთელობას აკვირდება, audit trail კი actor-ს, action-ს, target-ს, დროსა და შედეგს უნდა უკავშირებდეს. ორივე შეიძლება საჭირო იყოს, მაგრამ ერთი მეორეს არ ცვლის. audit log-ის არსებობა თავისთავად სამართლებრივ ან ინდუსტრიულ შესაბამისობასაც ვერ ადასტურებს: ამისთვის საჭიროა კონკრეტული სტანდარტი, პოლიტიკა, პროცედურები და დამოუკიდებელი შეფასება.</p>
